# Play Ashen Bond

Open **Windows/GAME JAM - 2026.exe** to play. Unity is not required.

Keep all files and folders in `Windows` together. If you downloaded the repository as a ZIP, extract it completely before launching.

The supplied executable comes from an existing build dated **18 October 2026, 06:38 PKT**. This final-build package was copied without rebuilding. Debug-only `DoNotShip` files were excluded. The packaged game has not received a new end-to-end playtest during upload preparation.

Use **Start Game → Easy** for a first playthrough. A/D moves, Shift runs, Space jumps, J fires, K dashes, P calls Mira, E heals, Q rewinds, and Esc pauses.

See the [judge quick start](../Docs/JUDGE_QUICK_START.md) and [game guide](../Docs/GAME_GUIDE.md).
