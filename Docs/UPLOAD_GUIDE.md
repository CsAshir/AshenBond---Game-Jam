```sh

```

Run **Play/Windows/GAME JAM - 2026.exe**. Unity is not needed for that route. Keep all runtime files together.

For source review, add the repository root in Unity Hub, use Unity **6000.3.8f1**, open **Assets/DarkForest/Scenes/MainMenu.unity**, and press Play.
